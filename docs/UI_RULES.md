# UI rules
- Personal puzzle: Add givens -> Confirm -> Solve.
- Confirm silently accepts a solvable puzzle and enters solve mode; invalid/unsolvable input asks for recheck.
- Clear Cell is always cell-only.
- Solve is scoped to the selected Cell, Row, Column, Box, or Entire Grid.
- Source givens are dark navy; user-entered numbers are blue.
- Candidate marks occupy fixed 3x3 slots inside fixed-size cells.
- No Save button.
- No 'check your puzzle' import warning.
- My Sudoku is for TOI/printed puzzles; Deccan Chronicle is daily backend-fed data.
